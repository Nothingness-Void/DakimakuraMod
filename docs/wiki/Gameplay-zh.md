## 1. 安装与兼容性要求

本 Mod 支持以下 5 种官方构建（可在 [Releases](https://github.com/Nothingness-Void/DakimakuraMod/releases) 下载）：

| Minecraft 版本 | Loader | 最低 Loader 版本 | 额外前置依赖 | 发布文件名后缀 |
|---|---|---|---|---|
| `1.20.1` | Forge | `47.1.47+` | 无 | `+mc1.20.1-forge.jar` |
| `1.20.1` | Fabric | Fabric Loader | **Fabric API**（必装） | `+mc1.20.1-fabric.jar` |
| `1.21.1` | NeoForge | `21.1.226+` | 无 | `+mc1.21.1-neoforge.jar` |
| `1.21.1` | Fabric | Fabric Loader | **Fabric API**（必装） | `+mc1.21.1-fabric.jar` |
| `1.21.1` | Forge | `52.1.14+` | 无 | `+mc1.21.1-forge.jar` |

> [!IMPORTANT]
> - 客户端与服务端**必须**使用相同的 Minecraft 版本与相同的 Loader（Forge、Fabric、NeoForge 之间不可混用）。
> - 使用 **Fabric** 时，客户端与服务端都必须安装对应版本的 **Fabric API**。
> - **自定义抱枕包只需放在服务端**（单人游戏放在本地客户端）；联机玩家加入服务器时会自动同步列表与纹理，无需手动安装抱枕包。

## 2. 合成与获取

### 空白抱枕（`dakimakuramod:dakimakura`）

有序合成（`2 行 × 3 列` 白色羊毛 `minecraft:white_wool`），产出 **1 个空白抱枕**：

```text
[白色羊毛] [白色羊毛] [白色羊毛]
[白色羊毛] [白色羊毛] [白色羊毛]
```

### 抱枕设计图（`dakimakuramod:dakimakura_design`）

- **获取方式**：当**玩家**击杀任意敌对生物（`Enemy`，如僵尸、骷髅、苦力怕等）时，有 **5%** 概率掉落 1 张空白设计图。
- **解锁设计**：手持空白设计图**右键**，会从当前已加载的所有抱枕包中随机抽取并解锁一款抱枕设计。

### 制作成品抱枕（应用设计图）

无序合成（在玩家背包 `2×2` 合成格中即可完成）：

- **材料**：`1 × 空白抱枕` + `1 × 已解锁的抱枕设计图`
- **产物**：对应图案的成品抱枕（会保留空白抱枕原有的正反面朝向状态）。

### 清洗抱枕（还原为空白）

无序合成（在玩家背包 `2×2` 合成格中即可完成）：

- **材料**：`1 × 成品抱枕` + `1 × 白色染料 (minecraft:white_dye)`
- **产物**：`1 × 空白抱枕`（可重新应用其他设计图）。

### 创造模式

在创造模式物品栏中设有独立的 **Dakimakura Mod** 标签页（图标会自动轮播缓存中的抱枕图案），内含空白设计图、空白抱枕以及按名称字母排序的所有已加载抱枕。

## 3. 摆放与操作控制

| 场景 | 操作 | 效果 |
|---|---|---|
| 手持抱枕 | **潜行（Shift）+ 右键空气** | 切换手中抱枕的正反面 |
| 放置在世界中 | **右键**地面上方 / 墙面侧面 / 天花板底面 | 摆放占用 **2 格**空间的抱枕（墙面垂直 2 格，天花板水平 2 格） |
| 世界中的抱枕 | **潜行（Shift）+ 右键** | 切换已摆放抱枕的正反面 |
| 世界中的抱枕 | **破坏**任意一格 | 完整破坏抱枕并掉落带有图案与翻面状态的物品 |
| 世界中的抱枕 | **鼠标中键（选取方块）** | 复制该抱枕的图案与当前正反面状态 |
| 放置在床上 | 手持抱枕**直接右键床** | 将抱枕摆放在床上（无需潜行，不会触发睡觉） |
| 床上的抱枕 | **潜行（Shift）+ 右键** | 切换床上抱枕的正反面 |
| 床上的抱枕 | **左键点击** | 仅取下/弹出床上的抱枕，**不会破坏床**（创造模式同样生效） |
| 床上的抱枕 | 破坏下方的床 | 床破坏时一并掉落床上的抱枕 |

## 4. 指令列表

| 指令 | 权限要求 | 适用范围 | 作用 |
|---|---|---|---|
| `/dakimakura openPackFolder` | `0`（所有玩家） | 客户端 / 单人游戏 | 在系统文件管理器中打开本地 `<gameDir>/dakimakura-mod/` 抱枕包目录 |
| `/dakimakura reload` | `2`（OP / 开启作弊） | 服务端 / 单人宿主 | 重新读取配置并扫描 `<gameDir>/dakimakura-mod/`，按 256 KiB 分批向所有在线玩家热同步最新抱枕列表，无需重启 |
